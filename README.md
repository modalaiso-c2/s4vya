# 💙 Savya — Application Web de Gestion Financière Intelligente

Savya est une application web moderne qui aide les utilisateurs à **gérer leur budget, suivre leurs dépenses** et **analyser leurs finances** grâce à une interface claire, minimaliste et intuitive.

> 🚀 Développée avec **React + TypeScript + TailwindCSS + shadcn-ui**, propulsée par **Lovable**.

## ✨ Fonctionnalités principales

- 🧾 **Suivi des dépenses et revenus**
- 📊 **Tableau de bord interactif** avec statistiques et graphiques
- 🔎 **Filtrage et recherche des transactions**
- 🤖 **Analyse IA simulée** (conseils financiers basés sur les données locales)
- 🌗 **Mode clair / sombre**
- 👤 **Système de compte utilisateur** : création, connexion, déconnexion, édition du profil et photo de profil
- ☁️ **Connexion Google via Firebase**
- 💾 **Sauvegarde locale (localStorage)** pour les données utilisateur

## ⚙️ Installation locale

### 🧰 Prérequis

- [Node.js](https://nodejs.org/) ≥ 18  
- [npm](https://www.npmjs.com/) ou [yarn](https://yarnpkg.com/)  
- (Optionnel) [Git](https://git-scm.com/) pour cloner le projet

### 🚀 Étapes

```bash
# 1. Cloner le dépôt
git clone https://github.com/modalaiso/savya.git

# 2. Se rendre dans le dossier
cd savya

# 3. Installer les dépendances
npm install

# 4. Lancer le serveur de développement
npm run dev
